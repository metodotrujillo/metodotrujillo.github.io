# Plan de implementación

1. Estructura Vite + React + TypeScript strict + Tailwind, identidad visual, home, rutas hash y Pages.
2. Lógica financiera pura, configuración colombiana con fuentes y pruebas de límites.
3. Interfaces, resultados en vivo, explicación y compartir.
4. Acceso, consentimiento, política, cola de envío y Apps Script para Sheets.
5. Auditoría de accesibilidad/rendimiento, SEO, imagen OG y guía operativa.

Cada fase tiene un commit independiente. Los enlaces de captura, comunidad y datos del responsable son configuración del propietario. Ningún dato de los simuladores se envía al registro.
